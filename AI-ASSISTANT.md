# Локальный AI-консультант Arvesemu

Консультант работает через Ollama и модель `qwen3:4b` на этом компьютере. Платный API не используется. Функция доступна пользователям с правом просмотра отчётов.

## Запуск

1. Запустите приложение Ollama для macOS.
2. Установите модель, если она ещё не загружена:

   ```sh
   ollama pull qwen3:4b
   ```

3. Откройте Arvesemu по адресу `http://127.0.0.1:8000` или `http://localhost:8000`, нажмите «AI-бухгалтер» и проверьте соединение.

Модель занимает около 2,5 ГБ. Ollama API должен быть доступен на `http://127.0.0.1:11434`.

## Доступные данные

Перед каждым вопросом приложение формирует контекст по выбранному периоду из активной организации: проводки, план счетов, счета продаж и поставщиков, оплаты, расходы, ручные журнальные записи и числовые проверки. Контакты, банковские реквизиты и учётные данные не отправляются. Большие наборы ограничиваются; количество пропущенных строк указывается в контексте анализа.

Данные передаются только локальному процессу Ollama через loopback-адрес `127.0.0.1`. Помощник не обращается к Supabase, не имеет функций сохранения/изменения/удаления и не записывает переписку в хранилище. Доступ к окну ограничен правом просмотра отчётов.

В первой версии содержимое вложенных PDF, изображений и сканов не читается; в AI не передаются сами файлы или их байты. Для вопросов по таким документам сначала внесите проверяемые реквизиты в соответствующий экран Arvesemu.

Если Ollama не подключается, сначала проверьте, что приложение запущено, сайт открыт по одному из адресов выше и модель `qwen3:4b` установлена. Не открывайте API Ollama для внешней сети и не используйте `OLLAMA_ORIGINS=*`.
